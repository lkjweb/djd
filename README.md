# Telegram Only Launcher

Это добровольный Android-лаунчер, а не вирус и не системная блокировка приложений.
Он показывает только кнопку запуска Telegram. Он **не скрывает, не удаляет и не блокирует**
остальные приложения.

## Сборка APK

1. Откройте папку проекта в Android Studio.
2. Дождитесь синхронизации Gradle.
3. Выберите **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
4. APK появится в `app/build/outputs/apk/debug/`.

Требуется Android Studio с JDK 17 и Android SDK 35.

## Как включить

1. Установите APK на своё устройство.
2. Нажмите Home и выберите **Telegram Only Launcher** как приложение «Главный экран».
3. Для возврата откройте кнопку **Выйти / сменить лаунчер** и выберите другой главный экран в настройках.

Для другого телефона Telegram должен быть установлен отдельно. Приложение не получает доступ к сообщениям,
контактам, файлам или учётной записи Telegram.
